Подсказки

  • Ctrl+Enter запускает текущий файл, Ctrl+S скачивает его.
  • Tab вставляет четыре пробела. Чтобы выйти из редактора, нажмите Esc, затем Tab.
  • Чтобы использовать input(), заранее впишите ответы в поле под консолью.
  • Открытые файлы лежат в одной рабочей папке Python. Из helpers.py можно импортировать через import helpers.
  • Стандартная библиотека Python доступна сразу после загрузки. Поддерживаемые Pyodide пакеты загружаются из интернета по импорту.
  • Вкладки, код, ввод и журнал сохраняются в этом браузере. Кнопка «Скачать .py» создаёт отдельный файл.
  • Запуск ограничен двумя минутами. Долгую программу можно остановить кнопкой «Стоп».
